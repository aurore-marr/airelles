📊 Taux de travail mensuel

  • Calculé sur les jours du mois couverts par le cycle (sélectionner le mois via les boutons)
  • Heures théoriques = jours ouvrés × durée de référence × taux agent
  • CA / CF / FO comptent comme présence dans les heures travaillées
  • MO / GR = 0h — EM = négatif sur la journée
  • Les heures supplémentaires (HS) et écarts horaires sont visibles par agent

📋 Règles congés — FPT / FPH

  • CA annuels : 17,5 jours — proratisés selon le taux de travail (ex : 80% → 14 j, 90% → 15,75 j arrondi à 0,5j)
  • Période principale : 1er mai – 31 octobre
  • ≥ 5 jours CA hors période → droit à +2 jours CF (fractionnement)
  • 3 ou 4 jours CA hors période → droit à +1 jour CF
  • Les RTT ne comptent pas pour le calcul du fractionnement
  • 🗓 Jours fériés travaillés : comptabilisés avec les dimanches travaillés — 10 dimanches/fériés = 14h de repos supplémentaire (30h pour les agents de nuit)

🏥 Import planning AS

Importez un planning AS depuis un fichier Excel (.xlsx) ou CSV. Chaque ligne = un agent (N° Poste), chaque colonne = un jour du cycle (1 à 42). Codes valides : M, S, J, R, RC, CA, CF, MO, EM, AT, FO, GR.
📋 Format (col A = Poste, B→AQ = Jours 1-42)
Ex ligne 2 : 273 | M | S | J | R | M | S | J | R | ...

💊 Import planning IDE

Même format que le planning AS mais pour les IDE. Fichier Excel (.xlsx) ou CSV. La colonne Poste doit commencer par I (ex: I01, I02…).

🔧 Import planning AUX

Importez un planning Auxiliaires depuis un fichier Excel (.xlsx) ou CSV. Même format que le planning AS — col A = N° Poste, colonnes B→AQ = Jours 1–42. Codes valides : M, S, J, R, RC, CA, CF, MO, EM, AT, FO, GR.

🧹 Import planning Entretien

Importez un planning Agents d'Entretien depuis un fichier Excel (.xlsx) ou CSV. Même format que le planning AS — col A = N° Poste, colonnes B→AQ = Jours 1–42. Codes valides : M, S, J, R, RC, CA, CF, MO, EM, AT, FO, GR.
